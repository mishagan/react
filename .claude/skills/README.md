# Project Skills

342 Claude Code skills vendored from the [alirezarezvani/claude-skills](https://github.com/alirezarezvani/claude-skills) library (MIT licensed — see LICENSE).

Each subdirectory is one skill (`<name>/SKILL.md`, plus any supporting files). Skills whose original names were generic and collided across plugins were prefixed with their plugin name (e.g. `agenthub-init`, `playwright-pro-review`, `self-improving-agent-status`, `handoff-engineering`).

To remove skills you don't need, delete their directories.
